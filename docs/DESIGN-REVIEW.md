## 保留的结构

ccg 的本地代理在 PopCat 前增加连接健康检查与新连接阻断。这一层服务于用户要求的常驻管理功能；所有代理仍由 PopCat 负责实际路由，不另做节点选择、TLS 解密或账号代理。

恢复记录与完整备份用途不同：完整备份供人工恢复；按字段记录让自动撤销保留用户后来修改的其他配置。删除字段记录、改成覆盖整份历史文件会损坏这一行为，因此保留。

CLI 与 Desktop 的账号配置目录仍分开。Desktop 使用自己管理的官方会话，不能为了复用函数而强行指向 CLI 的独立目录。

Desktop 仍有较多代码用于配置、恢复、诊断和启动。这些功能可在后续确有独立演进需要时拆文件；本次未增加管理器、接口层或通用工作流框架。

## 验证与边界

竞态测试与 vet 覆盖原有代理、凭据隔离、设置恢复，以及本次新增的重复 setup 不改文件、客户端选项复用同一服务、网络配置变化拒绝复用旧服务、后台进程脱离终端并保留指定日志。

真实 Claude Desktop 仍未安装，因此本次审查不确认 Desktop 实际代理覆盖或页面时区。此项需要安装官方应用后单独验收。
